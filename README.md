## Descripcion
Se desea crear una aplicacion web para el control de compras personales

## Funcionalidades

### Gestion de categorias
- Atributos (nombre, descripcion)

### Gestion de productos
- Atributos (nombre, tipo)

### Gestion de compra
- Atributos (producto, precio, cantidad, unidad medida)
